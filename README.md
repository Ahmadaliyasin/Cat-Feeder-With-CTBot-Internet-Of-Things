# Cat-Feeder-With-CTBot-Internet-Of-Things
Important: this CTbot can only use ArduinoJson 6.19. If you use the latest ArduinoJson versions, they cannot be used and will cause errors when compiling the Arduino. Before using the code, first create the bot on Telegram with @Botfather and obtain the API token. Then, copy the API token into the code. 
Component: 
-ESP32 Dev Module
-OLED 0.96-inch SSD1306
-Motor Servo SG90. 3.3-5V
Libraries:
-include <WiFi.h>
-include <CTBot.h>
-include <Adafruit_SSD1306.h>
-include <Wire.h>
-include <ESP32Servo.h>
-include <time.h>
-include <EEPROM.h>
